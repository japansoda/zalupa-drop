# 🚀 ZALUPA DROP v1.0.0 — Официальный релиз платформы

> **Премиальная платформа открытия кейсов, апгрейдов и мини-игр по CS2 нового поколения.**  
> Честная математика, молниеносный стек на Next.js 16 Turbopack, интеграция со Steam Community Market и честный Provably Fair RTP.

---

## 🌟 Главные фичи релиза

### 1. 📦 Кейсы CS2 и 25 авторских коллекций
* **Аутентичный CS2 Case Opening**:
  * Реализован оригинальный механизм Valve «Специальный Редкий Предмет»: вместо спойлера конкретного ножа в рулетке пролетает золотой секретный предмет с иконкой ножа/перчаток и знаком вопроса.
  * Реалистичная кривая распределения редкостей в ленте прокрутки (тайные и экстра-редкие предметы пролетают с аутентичной частотой).
  * Поддержка всех официальных ванильных кейсов CS2 (от классических Weapon Case и Bravo до Kilowatt, Gallery и Fever).
* **25 Новых Кастомных Кейсов**:
  * 25 уникальных тематических векторных 3D-кейсов (SVG) с индивидуальной неоновой подсветкой (`public/cases/`).
  * Каждый кейс содержит от 15 до 18 сбалансированных скинов с честным математическим ожиданием (RTP ~98%).
  * Топовые подборки: *«Легенда Howl»*, *«Вулкан & Огонь»*, *«Золотой Век»*, *«Градиентный Раш»*, *«Галактика Допплер»*, *«Дикий Лотос»*, *«Хранилище Перчаток»*, *«Грааль CS2»* и др.

---

### 2. ⚡ Умный Апгрейдер (Upgrader 2.0)
* **Интерактивный круговой радар**:
  * Плавная стрелка, расчет угла и динамический сектор шанса победы в реальном времени.
* **Лимит и Зелья Удачи (Luck Potions)**:
  * Максимальный суммарный шанс апгрейда строго ограничен **80%** (с учетом бонуса зелья).
  * Защита от переполнения: если базовый шанс уже достиг 80%, зелье не расходуется вхолостую.
  * Быстрые пресеты шансов: `1.5x`, `2x`, `5x`, `10x`, `20x`, а также фиксированные кнопки шанса `25%`, `50%`, `75%`.
* **Переработанный UX выбора категорий**:
  * Стильные табы с тематическими иконками (`★`, `🧤`, `🎯`, `⚡`, `🔫`, `💥`, `🛡️`, `🏷️`, `👤`, `🔑`).
  * Живой счетчик доступных скинов под текущую ставку для каждой категории.
  * Умная фильтрация: если предмет слишком дорогой или дешевый, алгоритм предлагает релевантные скины без мусора.

---

### 3. 🌐 Прямая интеграция со Steam Community Market
* **Прямые ссылки на лоты Steam**:
  * Переход со страницы предмета ведет напрямую на карточку конкретного скина на Торговой площадке Steam (`/market/listings/730/...`), а не в общий поиск:
    * Ножи и перчатки: `★ {Weapon} | {Skin} ({Wear})`
    * StatTrak™: `StatTrak™ {Weapon} | {Skin} ({Wear})`
    * Агенты: `{Agent Name} | {Faction}` (без лишних префиксов)
    * Наклейки: `Sticker | {Name}`
    * Брелоки: `Charm | {Name}`
* **Адаптивный парсер цен**:
  * Серверный API маршрут `/api/steam-price` с автоматическим in-memory кэшированием (30 мин).
  * Корректная обработка лимитов Steam API (429 Rate Limit) и редких коллекционных предметов с мгновенным безопасным фоллбэком.

---

### 4. 🧹 Очищенная и реалистичная база скинов CS2
* **Полное соответствие правилам CS2**:
  * **Брелоки (Charms)**, **Агенты (Agents)** и **Наклейки (Stickers)** очищены от некорректных качеств износа (`FN`, `MW`, `FT`, `WW`, `BS`).
  * С агентов и брелоков удален невозможный `StatTrak`.
  * Устранены дубликаты, оптимизировано более 28,900 скинов.

---

### 5. 💎 Live Drops и социальная динамика
* **Лента живых дропов без ботов**:
  * Убраны фейковые аватарки и бессмысленные бот-ники.
  * Чистый премиальный дизайн карточек: акцент на скине, названии кейса, износе и стоимости в DropCoin (DC).
  * **Реальные дропы игроков**: выигрыши с кейсов, апгрейдера и контрактов мгновенно попадают в общую ленту со специальным бейджем `LIVE`.

---

### 6. 🖱️ Улучшения эргономики и UX
* **Горизонтальный скролл колесиком мыши**:
  * Глобальный `HorizontalScrollManager` переводит вертикальную прокрутку колесика в горизонтальное смещение для всех лент, табов и галерей скинов.
* **Инвентарь игрока**:
  * Продажа предметов поштучно при наведении на карточку или массовая продажа в один клик.
  * Мгновенное зачисление на баланс в DropCoin (DC).
* **Контракты обмена (Trade-Up Contracts)**:
  * Режим обмена 10 скинов одного грейда на скин более высокой ценности с визуализацией шансов.
* **Crash Game**:
  * Динамический множитель и быстрые раунды с автостопом.

## ⚡ Быстрый старт

### Требования
* Node.js 18.17+ или 20+
* Менеджер пакетов `npm`, `pnpm` или `yarn`

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/japansoda/zalupa-drop.git

# Перейти в каталог проекта
cd zalupa-drop

# Установить зависимости
npm install

# Запустить локальный сервер разработки
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для продакшена

```bash
npm run build
npm run start
```
